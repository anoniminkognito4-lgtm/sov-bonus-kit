# M2 — реестр и загрузчики

Готовы SQLite-реестр на SQLAlchemy 2, загрузчики источников из samples,
предпросмотр, атомарное применение, журнал, история версий и откат.
Адаптер собирает вход движка из реестра, без чтения tests/cases или эталонов.

## Что работает

- Тип файла определяется по заголовкам, независимо от имени файла.
- CSV читаются с UTF-8/BOM и разделителем `;`; даты ISO и `ДД.ММ.ГГГГ`,
  числа с точкой и запятой приводятся к единому формату.
- xlsx вех читается без Excel и LibreOffice. Для выгрузки без кодов
  работает сопоставление по составному ключу с предупреждением.
- Несопоставленные строки видны в предпросмотре и не попадают в реестр.
  Ошибки структуры, значений и противоречивые дубликаты запрещают применение.
- Предпросмотр не изменяет базу. Изменившийся файл или устаревший
  предпросмотр требуют повторной проверки.
- Повторная загрузка всех образцов не меняет данные, журнал и список загрузок.
- Применение и журнал записываются одной транзакцией. Ошибка записи
  откатывает изменения целиком.
- Откат восстанавливает предыдущие значения и сохраняет историю.
  Он не может стереть более поздние правки или оставить записи без
  сотрудника, проекта, этапа, назначения или вехи.
- Закрытый снимок сохраняет данные и редакцию правил. Откат загрузок,
  предшествовавших закрытию, запрещён; последующие загрузки снимок не меняют.
  Интерфейс закрытия и начисления будут реализованы в M3.
- Истории БГБ и загрузки пересекаются по датам. У ушедшего сотрудника
  последний БГБ и загрузка продлеваются до планового окончания для ПБ.
- NPV и доля БС выбираются по кварталу каждой вехи; NPV ухода — по
  кварталу ухода. Проценты считаются по отрезкам истории ставок.

## Как проверить

Команды одинаковы для Windows и macOS при установленном uv. Для локального
uv на текущем Mac сначала выполните настройку PATH из M0.md.

```text
uv run pytest -q
uv run ruff check . tools/compare_registry_golden.py
uv run ruff format --check . tools/compare_registry_golden.py
uv run python -m sov.registry.cli samples build/sov.sqlite build/registry-results
uv run python tools/compare_registry_golden.py build/registry-results
```

Созданы демонстрационная база `build/sov.sqlite` и расчёты
`build/registry-results/*.json`. Эти файлы не входят в Git.

Результат на macOS, 14.10.2026: **202 теста прошли**. Пакетная сверка по
реестру: **0 из 27 кейсов с расхождениями**. T16 и T20 сверяются без
процентов, как предусмотрено CLAUDE.md: samples содержит только условную
ставку 16%, а исходные кейсы используют другие ставки. Все остальные
кейсы сверяются полностью, включая проценты. Из реестра рассчитаны 28
кейсов; T11b не имеет Excel-эталона и остаётся кейсом автоконтроля.

Проверены повторная загрузка всего комплекта, полный откат в обратном
порядке зависимостей, история обновления, устаревший предпросмотр,
изменённый файл, отказ транзакции, защита снимка и кириллица в пути SQLite.
Также проверены переменная ставка и разные NPV/доли БС по кварталам.
Все прежние проверки M1 проходят. Шаблон, эталоны и samples не изменены.

## Особенности образцов и следующий этап

Из 18 файлов samples загружаются 16 файлов-источников. case_map.csv — карта
для сверки, payroll_export_sample.csv — пример выгрузки, их не импортируем
как предметные данные. В rp_project_sets.csv три несопоставленные строки:
T9001/T9002 и проекты TP-RP-A/B/C отсутствуют в справочниках. Они видны в
списке разбора; искусственные справочники для них не добавлялись.

При нескольких версиях ФМ одного квартала адаптер сообщает о необходимости
выбора версии. Автоматическое правило выбора не выдумывается. Нормирование
ЗРП и толкования И-1…И-8 по-прежнему требуют методологического согласования.

Таблицы начислений, параметров и ручных решений подготовлены; пользовательские
сценарии записи начислений, закрытия квартала, прав и выгрузок — следующий M3.
Особые правила перераспределения и переводов — M6. Корпоративные подключения
к 1С в прототипе заменены загрузкой условных выгрузок файлами.

Windows остаётся целевой платформой. Использованы переносимые пути,
SQLAlchemy URL для пути базы и явный UTF-8. Фактический запуск на Windows
пока не проверен и остаётся обязательным перед эксплуатацией.
