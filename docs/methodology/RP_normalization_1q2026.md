# 1. Правила определения загрузки РП
Назначение РП на проект зависит от ранга РП и сложности проекта.
Сложность проекта зависит от трех основных критериев (Класс, Площадь, Этап) и одного вспомогательного критерия (количество дополнительных объектов). Перечень дополнительных объектов представлен в Приложении 1.
Расчет сложности одного проекта осуществляется путем перемножения основных коэффициентов. При имеющихся доп. объектах к произведению основных коэффициентов прибавляется надбавка за каждый такой объект.
Итоговая загрузка РП определяется, как сумма загрузки по каждому проекту.
Если в проекте есть очереди, они рассчитываются, как отдельный проект (начиная со второго этапа СОВ). При расчёте к произведению коэффициентов применяется понижающий коэффициент 0,85 (по каждой очереди). Если на очередях проекта есть доп. объекты, то понижающий коэффициент 0,85 применяется к сумме баллов по проекту и надбавке за доп. объекты.
Если в проекте есть Бизнес-центр, Торговый Центр, ФОК, они считаются отдельными очередями с классом, аналогичным классу проекта (и выделяется при расчете загрузки согласно п.5).
При определении загрузки для Логистического центра применяется поправочный коэффициент 0,7 к произведению основных параметров (коэффициент принят экспертно, в ввиду наличия внешнего генподрядчика).

# 5. Правила расчета БГБ
Если сумма коэффициентов сложности по проектам меньше либо равна установленному коэффициенту для расчета бонуса, то размер базы бонуса = 100%, если больше, то база бонуса считается по формуле (x/y-1)*2+1, где:х – итоговый к-т загрузки (сумма всех проектов);у – коэффициент для расчета бонуса (в зависимости от ранга).

Коэффициенты для расчета % загруженности РП в зависимости от ранга:
РП 1 ранга = 1,2
РП 2 ранга = 1
РП 3 ранга = 0,8

Например:
РП 1 ранга, 2 проекта в управлении:
Элит, XXL, Этап 1
Премиум, M, Этап 4
Общий K загрузки = 1,38
% загруженности для расчета ПБ = (1,38 / 1,2 - 1) * 2+1 = 130%
