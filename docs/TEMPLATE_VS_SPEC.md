## Известные расхождения для параллельного расчёта

- **Вехи из двух частей** (сл. 55, п. 19; D-052). Шаблон даёт каждой строке «(часть 1)» и «(часть 2)» полный вес 1/n, как обычной вехе. По СОВ каждая часть весит половину одной вехи, а опережение второй части бонус не увеличивает. Пул авансов (ПБ × доля авансов) тот же, переплаты в сумме нет: это перекос между вехами — части получают больше, остальные вехи меньше, и выплаты сдвигаются во времени. В параллельном расчёте такие этапы будут расходиться с калькуляторами по суммам отдельных вех.

- **Таблица загрузки v2** (D-059). С 01.07.2026 загрузка ДРП, ГИП ИС на объектах СКБ и старших менеджеров БС на 2 этапе считается по слайду 18 v2, а Excel-калькуляторы — по таблице макрокниги. Такие назначения помечены проблемой `LOAD_TABLE_V2`: расхождение ожидаемое.
