# M0 — каркас прототипа

Это отчёт на момент завершения M0. Расчётные заглушки затем реализованы
на M1; текущие команды и результаты — в [M1.md](M1.md).

Созданы пакет `src/sov`, папки реестра, загрузчиков, адаптеров, выгрузок и
сервисов, заглушка панели Streamlit, контракт движка и пакетный CLI.
Расчётные правила пока не реализованы: заглушки явно вызывают
`NotImplementedError`, а не возвращают условные суммы.

## Окружение

Python 3.12, зависимости в `.venv`, точные версии закреплены в `uv.lock`.
Системный Python не изменяется. Если `uv` ещё не установлен в системе,
в этой рабочей папке используется локальная установка `.tools/uv/bin/uv`.
В новом терминале из папки проекта:

```bash
export PATH="$PWD/.tools/uv/bin:$PATH"
export UV_CACHE_DIR="$PWD/.uv-cache"
uv sync --locked
```

Локальная установка `uv`, окружение и кеш не входят в Git. При переносе
проекта на другую машину понадобится установить `uv` по инструкции README.

## Проверка

```bash
uv run pytest --collect-only -q
uv run pytest -m 'not m1' -q
uv run pytest -q --tb=no
uv run ruff check .
uv run ruff format --check .
uv run python -m sov.engine.cli --help
```

- Проверки каркаса: 3 теста должны проходить.
- Движок M1: 75 юнит-кейсов, 27 эталонов и 13 автоконтролей — всего
  115 тестов должны падать с `NotImplementedError` до реализации M1.
- Полный запуск pytest на M0 возвращает ненулевой код: это предусмотренный
  инструкцией этап, а не завершённый движок. Падающие проверки не скрыты
  через `skip` или `xfail`.
- T11b проверяется автоконтролем A08; T19 — юнит-кейсами нормирования.
- Суммы эталонов сравниваются с допуском 0,01 ₽, коэффициенты — 1e-9,
  даты и статусы — точно, через штатный `tools.compare_golden.compare`.

Начиная с M1, для завершения этапа полный набор соответствующих тестов
должен быть зелёным. Эталоны и исходный шаблон на M0 не изменяются.

## Результат проверки 14.10.2026

- Окружение: Python 3.12.14, установка зависимостей завершена.
- Сбор pytest: 118 тестов, ошибок сбора нет.
- Проверки каркаса: 3 passed, 115 deselected.
- Полный набор: 115 failed, 3 passed; все 115 ошибок — `NotImplementedError`.
- `ruff check`: без ошибок; форматирование всех 17 Python-файлов проверено.
- CLI `--help`: работает. Расчётные результаты появятся на M1.
- Машинный отчёт проверки: `build/m0-tests.xml` (не входит в Git).
