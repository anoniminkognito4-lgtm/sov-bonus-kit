# M1 — расчётный движок

Реализован чистый `calculate_case(case, params)` с результатом `sov-result/1`.
Движок использует только стандартную библиотеку Python, не читает файлы,
не обращается к сети, базе и текущей дате и не изменяет входной кейс.
Файлы читает отдельный CLI. Все пути в нём — через `pathlib`, текст — UTF-8,
на входе также поддерживается UTF-8 с BOM.

## Что готово

- ПБ по периодам БГБ и загрузки, длительность, участие и веса вех.
- К фин, низкий NPV, множитель БС 90/10, сроки, потолок авансов, KPI МП.
- Авансы, финал, остаток при уходе, нулевые и приостановленные выплаты.
- Выплаты 50/25/25, задержанная часть 25%, правила пятого этапа.
- Проценты по заданным в кейсах ставкам, перенос дат с выходных и праздников.
- Автоконтроли A01–A13 и отдельные проверки неполных данных.
- Неизменяемая таблица параметров редакции `SOV-v2-2026Q3`; спорные
  толкования реализованы в отдельных функциях по CALC_RULES.
- CLI для расчёта папки кейсов. При ошибке во входных данных новые результаты
  не записываются; папка результатов не может совпадать с папкой кейсов.

## Как проверить

Если `uv` установлен системно, команды ниже одинаковы на Windows и macOS.
Для локальной установки в текущей папке Mac сначала выполните команды
настройки PATH и кеша из M0.md.

```text
uv run pytest -q
uv run ruff check .
uv run ruff format --check .
uv run python -m sov.engine.cli tests/cases build/results
uv run python tools/compare_golden.py build/results
```

Результат на macOS, 14.10.2026: **155 тестов прошли**, включая 75 проверок
формул, 27 эталонов и 13 автоконтролей. Ruff и форматирование проходят.
Штатная пакетная сверка: **0 из 27 кейсов с расхождениями**. Допуск сумм —
0,01 ₽, коэффициентов — 1e-9; даты и статусы совпадают точно.

Для самостоятельной проверки откройте `build/results/T13.json` и
`WORKED_EXAMPLE.md`: ПБ 3 603 287,67 ₽, финал 1 909 742,47 ₽,
проценты 155 026,27 ₽, итого к выплате 4 478 971,47 ₽.
В JSON промежуточные суммы сохранены без округления.

## Что дальше

На M2 появятся реестр, загрузчики и адаптер реестра к входу движка.
История ставок и квартальные NPV будут собираться адаптером; сейчас движок
считает формат условного кейса со ставками по вехам и заданными NPV.
Контроли, зависящие от прошлого расчёта и утверждённого набора проектов,
относятся к реестру. Особые случаи §13 остаются для M6.

Нормирование ЗРП не определено методологией; согласование толкований
И-1…И-8 с Группой СОВ по-прежнему требуется. Эталоны и шаблон не изменены.

**Windows — целевая платформа.** Проверена работа с кириллицей, BOM и
пробелами в путях, без shell-команд внутри CLI. Эти проверки сейчас
выполнены на macOS. Фактическая установка и запуск на Windows пока
не проверены; они обязательны перед эксплуатацией.
