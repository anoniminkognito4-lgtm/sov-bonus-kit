# M3 — панель Группы СОВ

Готовы восемь разделов Streamlit: обзор квартала, сотрудники, проекты,
загрузка, проблемы, ручные решения, расчёт/закрытие и журнал. Интерфейс
на русском; панель открывается в браузере и работает локально.

## Запуск

```text
uv run streamlit run app/main.py
```

Адрес: http://127.0.0.1:8501. Для локального uv в текущей папке Mac сначала
выполните настройку PATH из M0.md. Эти команды подходят Windows при
установленном uv; запуск на самой Windows пока не проверен.

По умолчанию используется `build/sov.sqlite`, подготовленная на M2.
Для другой базы можно задать переменную окружения `SOV_DB_PATH`.
Статистика использования Streamlit отключена, сервер слушает только 127.0.0.1.

## Что работает

- Загрузка условного файла CSV/xlsx: предпросмотр каждой строки, применение,
  список загрузок и откат. Можно загрузить весь комплект образцов одной кнопкой.
- Карточка сотрудника: назначения, вехи, ПБ, коэффициенты, финал, части,
  проценты, история БГБ/загрузки, начислений и решений. Фильтры по блоку,
  проекту, категории, уходу и статусу суммы.
- Проект: этапы, плановые/фактические сроки вех, NPV по кварталам и команда.
- Проблемы: блокирующие/предупреждения, переход в карточку, выгрузка списка.
- Решения по стартовому NPV, опережению >100 дней, расходной части пятого
  этапа и выплате вне сессии: основание и ссылка на файл обязательны.
  Дата вне сессии участвует в пересчёте процентов общим движком.
- Перераспределение пока сохраняется для ручного расчёта с блокировкой;
  автоматическая формула и ограничения относятся к M6.
- Расчёт всех или выбранных назначений. ФМ без утверждения ФЮБ — прогноз;
  прогнозы и блокирующие проблемы не допускаются к закрытию и payroll.
- Сравнение с предыдущим расчётом того же квартала: изменение >10% —
  предупреждение. Сводная отдельно сравнивается с прошлым кварталом.
- Закрытие атомарно фиксирует данные, параметры, редакцию, результаты и
  начисления. Нельзя закрыть устаревший, частичный, пустой или проблемный
  расчёт. Последующие правки не меняют уже закрытые суммы и выгрузку.
- Файл к начислению xlsx/CSV только из закрытого снимка; проценты отдельными
  строками, деньги округляются до копеек только при экспорте.
- Выписка «калькулятор» xlsx, сводная xlsx, проблемы и ручной расчёт CSV.
  В xlsx только значения; предварительные выписки имеют соответствующую пометку.
- Журнал изменений, просмотров карточек и скачивания выгрузок.
- Роли проверяются сервисным слоем. На M3 действует панель Группы СОВ;
  кабинеты сотрудника и руководителя подключаются в M5. Вход демонстрационный.

## Самостоятельная проверка условного квартала

1. В разделе «Загрузка» нажмите «Загрузить все условные образцы».
2. Выберите квартал `2026-Q3`. В «Расчёт и закрытие» нажмите «Рассчитать».
   Закрытие должно быть недоступно: в исходных образцах нет утверждения ФЮБ,
   у T0022 пропущен KPI, а T0039 требует решения по опережению.
3. Создайте условные исправления, не меняя samples:

   ```text
   uv run python tools/make_panel_demo.py
   ```

4. В «Загрузка» выберите по очереди файлы `build/demo-corrections/npv_quarterly.csv`
   и `build/demo-corrections/kpi_mp.csv`. Каждый раз — «Предпросмотр» → «Применить».
   Они добавляют условное утверждение ФЮБ и KPI 80% для T0022 за 2025-Q4.
5. В «Ручные решения» выберите T0039 / TP-T18, решение по опережению,
   поставьте подтверждение, укажите условное основание и имя условного письма.
   Нажмите «Сохранить решение».
6. Рассчитайте **все** назначения за 2026-Q3, закройте квартал и скачайте
   файл к начислению. После закрытия кнопки повторного закрытия нет.
7. Любое последующее изменение исходных данных не должно менять этот файл.

Это демонстрационные согласования на условных данных, не согласование реальных выплат.
Три строки нормирования РП без справочников остаются несопоставленными, как на M2.

## Проверки

Основной набор и последующие проверки изменений: **216 тестов прошли**.
Включены все прежние тесты M1/M2, проверки прав, прогнозов, устаревшего и
частичного расчёта, атомарности закрытия, неизменности выгрузки и округления.
Smoke-тесты `streamlit.testing.v1.AppTest` проверяют все разделы и сценарий
исправления → ручное решение → пересчёт → закрытие → доступность выгрузок.
FileUploader не управляется AppTest: в тесте вводится готовый предпросмотр
условного файла, затем применение выполняется через интерфейс.
Выбор файла в системном диалоге этим тестом не проверяется.

Панель дополнительно запущена локально и визуально проверена в браузере.
Ruff и форматирование проходят. Шаблон, эталоны и samples не изменены.
