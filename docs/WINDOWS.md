# Установка и приёмка на Windows

Целевая среда прототипа — Windows 10/11 x64, Python 3.12, локальная папка
пользователя. На macOS выполнены автоматические проверки; **нативный запуск
Windows ещё не подтверждён**. Сам факт наличия `.bat` не является приёмкой.
Вход в программе демонстрационный. Для эксплуатации на реальных данных
потребуются корпоративная авторизация, права и согласование HRIT.

## Установка один раз

1. Распакуйте переносимый комплект, например в `C:\SOV\sov-bonus-kit`.
   Папка должна быть доступна на запись вашему пользователю.
   Не переносите `.venv` с Mac: Windows создаёт своё окружение.
2. Установите uv. Команда в Windows Terminal / PowerShell:

   ```text
   winget install --id=astral-sh.uv -e
   ```

   Если WinGet недоступен, используйте [официальную инструкцию uv](https://docs.astral.sh/uv/getting-started/installation/).
   Перезапустите терминал после установки.
3. Дважды нажмите **setup.bat**. Этот шаг устанавливает Python 3.12 и зависимости
   из `uv.lock`, включая средства проверки. Для первой установки нужен доступ
   к источникам пакетов либо заранее подготовленный кеш **для Windows x64**.
   Кеш Mac и папка `.venv` Mac не заменяют Windows-окружение.
4. После успешной установки дважды нажмите **run.bat** и откройте
   http://127.0.0.1:8501. Обычный запуск использует установленное окружение
   напрямую и не скачивает пакеты. Office и LibreOffice для работы не нужны.

Установка не входит в повседневный запуск. При обновлении исходного комплекта
повторите `setup.bat` с тем же `uv.lock` новой версии. Перед заменой рабочей БД
сделайте копию `build/sov.sqlite` при остановленном приложении. Не заменяйте
свою БД демонстрационной: архив поставляется без БД.

## Автоматическая приёмка

Дважды нажмите **check.bat**. Он запускает:

- полный pytest, включая права, Streamlit AppTest и особые случаи;
- Ruff и форматирование;
- CLI движка и 27 эталонов;
- импорт CSV/xlsx в SQLite и сверку расчёта по реестру;
- исправление условных источников, закрытие квартала и выгрузки xlsx/CSV;
- кабинет, «что если» и контроль хэша БД;
- пути с кириллицей и пробелами.

Отчёт и подробные логи сохраняются в новой подпапке `build/acceptance`.
`report.json` содержит ОС, архитектуру, Python, хэш lock-файла, команды,
результаты и флаг `windows_verified`. Флаг становится `true` только после
успешного запуска на Windows. На Mac `--require-windows` завершается отказом.
Автоматический отчёт не подтверждает поведение системного браузера и диалога файлов.

## Проверка в браузере на Windows

После успешного `check.bat` выполните и отметьте:

- [ ] `run.bat` запускается из папки с пробелами и кириллицей.
- [ ] Откройте «Загрузка», загрузите все условные образцы. Через системный
      выбор файла проверьте CSV и xlsx; имена и русские тексты отображаются корректно.
- [ ] Пройдите квартал по `docs/M3.md`: проблемы → исправления → расчёт → закрытие.
- [ ] Скачайте payroll xlsx/CSV и выписку. Файлы читаются, суммы и кириллица корректны.
      Если проверяете без Excel, достаточно встроенной проверки openpyxl и просмотра CSV.
- [ ] Проверьте «Что если» и сброс по `docs/M4.md`. Основной расчёт не изменяется.
- [ ] Сотрудник T0002 видит только себя. Руководитель T0003 видит разрешённый
      TP-T02 и T0002/T0003, без БГБ; выгрузка также ограничена.
- [ ] Остановите приложение Ctrl+C, запустите вновь. Источники и закрытый квартал сохранены.
- [ ] Отключите сеть и снова выполните `run.bat`; панель и расчёт работают.

До выполнения этого списка статус Windows-приёмки остаётся открытым.
Запишите дату, Windows-сборку, браузер, путь `report.json` и результат каждого пункта.

## macOS

Для первого развёртывания с установленным uv: `sh setup.sh`.
Запуск после установки: `sh run.sh`. Проверки: `.venv/bin/python tools/acceptance.py`.
Проверка на macOS создаёт отчёт `system=Darwin`, `windows_verified=false`.
Команда запуска из предыдущих этапов `uv run streamlit run app/main.py`
также остаётся доступна, но готовые стартовые скрипты используют `.venv` напрямую.

## Что передавать на Windows

`build/sov-bonus-kit-portable.zip` содержит исходный комплект, тесты, условные
образцы и инструкции. В нём нет окружения Mac, локальной БД и кешей.
Архив предназначен для внутренней передачи: методология из исходного комплекта
не публикуется наружу. Сборка архива: `python tools/package_release.py`.
